# Personal Intro Project

## Project Overview and Objectives
The objective of this project is to create a lightweight, interactive command-line application in Python. The program is designed to demonstrate fundamental programming concepts—such as standard input/output operations and variable assignment—by asking the user a series of personal questions and returning a customized, friendly greeting.
